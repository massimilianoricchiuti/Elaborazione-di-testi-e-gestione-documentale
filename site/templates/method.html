Progetto e metodo

Obiettivo e perimetro

Il progetto trasforma fonti eterogenee relative ai contratti pubblici in una collezione di documenti XML validati, ne estrae informazioni territoriali, cronologiche ed economiche e genera un sito HTML statico. Il campione contiene {{ analysis.metadata.record_count }} documenti XML, tutti verificati rispetto alla DTD.

Pipeline riproducibile

  1. PreparazioneCSV, JSON, HTML, PDF e altri documenti testuali vengono ricondotti al CIG pertinente.
  2. ValidazioneOgni XML è analizzato e validato rispetto a contratto_cig.dtd; un errore interrompe la build.
  3. EstrazioneGli XPath alimentano un modello intermedio uniforme, indipendente dai template HTML.
  4. AnalisiTerritorio, date, importi, testo e PDF confluiscono nei risultati JSON e nella relazione.
  5. PubblicazioneJinja2 genera pagine navigabili, download locali, grafici SVG e annotazioni microdata.

Content model misto

La DTD non descrive soltanto campi strutturati. Due elementi alternano testo discorsivo ed elementi semantici ripetibili, secondo la forma prevista da XML per un content model misto.

<!ELEMENT descrizioneDocumentale
  (#PCDATA | tipologia | oggetto | categoria | termine | luogo)*>
<!ELEMENT fonteWeb
  (#PCDATA | titoloFonte | enteFonte | faseFonte | nessoFonte | datoFonte)*>

descrizioneDocumentale sintetizza il contratto; ogni fonteWeb intreccia invece titolo, ente, fase, riscontro e dato utile in una frase leggibile. Gli attributi conservano tipo documentale, MIME type, URL, classe di relazione e data di verifica. La separazione fra struttura, contenuto e presentazione rimane così esplicita.

06 / Compilazione

Istruzioni per la compilazione del progetto

Dalla radice del repository, con Python 3.11 o successivo, crea e attiva un ambiente virtuale. Su Linux e macOS:

python3 -m venv .venv
source .venv/bin/activate

Su Windows PowerShell:

py -3 -m venv .venv
.venv\Scripts\Activate.ps1

Installa le dipendenze, rigenera XML e sito ed esegui i controlli:

python -m pip install -r requirements-dev.txt
python scripts/build_all.py
python -m pytest

La compilazione della relazione richiede una distribuzione LaTeX con pdflatex. Se non è disponibile, il sito utilizza il PDF già presente nel repository. Per consultare il risultato:

python -m http.server 8000 --directory dist

Apri http://localhost:8000/ nel browser.
